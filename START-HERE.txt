🚀 QUICK START (5 minutes):

   1. Open TWO terminal windows

   2. Terminal 1 - Start Backend:
      > cd backend
      > npm install
      > node server.js

   3. Terminal 2 - Start Frontend:
      > cd frontend  
      > npm install
      > npm start

   4. Browser opens automatically at http://localhost:3000

   5. Try it:
      - Search for "AAPL"
      - Click on Apple Inc.
      - Click "Analyze Volatility"
      - See the magic happen! ✨
